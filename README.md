## 📖 Tentang Aplikasi

Aplikasi web kalender pendidikan untuk **UPT SD Negeri 55 Otting** yang menampilkan seluruh kegiatan akademik selama tahun ajaran 2026/2027.


## ✨ Fitur Unggulan

| Fitur | Keterangan |
|-------|------------|
| 📅 **Kalender Bulanan** | Tampilan per bulan dengan semua tanggal |
| 🔄 **Navigasi Semester** | Semester 1, Semester 2, atau Full Year |
| 🔍 **Pencarian** | Cari kegiatan berdasarkan kata kunci |
| 🎨 **Legenda Warna** | Identifikasi jenis kegiatan dengan mudah |
| 🖨️ **Cetak / PDF** | Simpan sebagai dokumen fisik |
| 📱 **Responsif** | Akses dari semua perangkat |
| 🌙 **Mode Gelap** | Nyaman digunakan di malam hari |
| 🖱️ **Interaktif** | Klik kegiatan untuk detail lengkap |

## 📅 Cakupan Kalender

### Semester 1 (Juli - Desember 2026)
- MPLS (13-17 Juli)
- Hari Kemerdekaan RI (17 Agustus)
- Maulid Nabi (25 Agustus)
- Asesmen Sumatif Semester 1 (30 Nov - 12 Des)
- Penyerahan Rapor (19 Des)
- Libur Semester 1 (21 Des - 2 Jan)

### Semester 2 (Januari - Juni 2027)
- Tahun Baru (1 Jan)
- Isra Mi'raj (5 Jan)
- Imlek (6 Feb)
- Nyepi (9 Mar)
- Idul Fitri (10-11 Mar)
- TKA (5-8 & 12-15 Apr)
- Idul Adha (17 Mei)
- Waisak (20 Mei)
- Asesmen Sumatif Semester 2 (8-19 Jun)
- Penyerahan Rapor (26 Jun)
- Libur Semester 2 (28 Jun - 10 Jul)
